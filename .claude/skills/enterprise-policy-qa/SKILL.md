# 企业制度问答

## 功能定位

面向员工和管理人员的制度查询需求，帮助使用者从已上传或已入库的企业制度中快速找到依据。该 skill 只完成"检索制度依据并生成答复"这一步，不替代综合部或制度归口部门作出最终解释。

## 处理流程

### 第一步：确认输入

开始工作前，确认以下信息是否已提供。如有缺失，礼貌询问用户：

1. **制度文件来源**（至少提供一项）：
   - 用户已上传的具体文件路径
   - 存放制度文件的目录路径
   - 平台已预置的制度库名称/标识
2. **员工问题**：自然语言描述的问题，例如"请假需要提前多久申请"
3. **可选限定条件**：制度名称、适用部门、发布时间、版本状态等

如果用户说"不确定制度名称"，先帮用户检索可能相关的制度，列出候选制度名称供用户确认。

### 第二步：检索相关制度原文

根据用户提供的信息执行检索，推荐工具：

1. **若用户提供了具体文件路径**：使用 `Read` 直接读取该文件
2. **若用户提供了目录路径**：使用 `Glob` 查找目录下的 Word、PDF、文本文件，然后根据问题内容用 `Grep` 筛选最相关的文件
3. **若用户指定了制度库/制度名称**：优先在文件名称或内容中匹配该名称

检索策略：
- 从用户问题中提取关键词（如"请假""提前""申请"）
- 使用 `Grep` 在文件中搜索关键词，优先考虑同时出现多个关键词的文件
- 读取匹配度最高的 1-3 个文件的相关章节
- 如果文件较大，先搜索关键词出现的位置，再读取前后上下文（±5-10 行）

### 第三步：提取制度信息

从检索到的原文中准确提取：

1. **制度全称**：必须原文照抄，不得简化或改写
2. **章节/条款位置**：如"第三章第十二条"、"第 5.2 节"等，必须原文标注
3. **适用对象/范围**：如适用部门、岗位层级等限定条件
4. **版本/发布时间**：如有多个版本，确认检索到的是最新有效版本

**绝对禁止**：编造制度名称、条款编号、审批流程或原文中不存在的内容。如果原文表述模糊，如实说明"原文未明确"，不可自行推断填补。

### 第四步：生成答复

按照以下结构生成最终答复：

```
**简明结论**：用 1-2 句话直接回答用户问题。

**置信度**：高（原文明确）/ 中（原文相关但需结合上下文）/ 低（仅检索到间接依据）

**制度依据**：
- 制度名称：《xxx》
- 条款位置：第 x 章第 x 条 / 第 x 节
- 原文摘录：[引用原文关键句子，保持原文措辞]

**适用说明**：
- 适用对象/部门：xxx（如原文有说明）
- 版本状态：现行有效 / 已废止（需说明）

**风险提示**：
- [如有特殊情况、例外条款、前置条件等，在此说明]
- [如涉及争议性解释，提示"具体执行以归口部门解释为准"]

**未明确事项**：
- [如原文对某方面未作规定，如实说明，不得臆测]
```

### 第五步：异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| **文件不存在/无法读取** | 明确告知用户无法访问该路径，请检查文件权限或重新上传。不得基于假设继续作答。 |
| **PDF/Word 等二进制文件无法解析** | 告知用户当前工具限制，建议提供文本版本、粘贴相关章节，或转换为可读的文本格式后再试。 |
| **检索到相互矛盾的条款** | 列出所有冲突依据，标注各自的制度名称、条款位置和版本号。提示用户以最新版本为准，或联系归口部门裁决，不做主观判断。 |
| **多个版本并存** | 优先引用最新版本，如无法判断哪个最新，列出各版本的依据并说明差异，提示用户向综合部确认有效版本。 |
| **未检索到明确依据** | 按下方"未检索到明确依据时的处理"格式答复。 |

### 未检索到明确依据时的处理

如果经过检索后无法找到与用户问题直接相关的制度条款，按以下格式答复：

```
**检索结果**：未在已提供的制度文件中找到与您问题直接相关的条款。

**已检索范围**：
- 检索的文件清单：[列出实际检索过的文件名称]
- 检索关键词：[列出使用的关键词]

**建议**：
1. 确认是否使用了正确的制度文件或版本
2. 尝试用其他关键词描述您的问题
3. 如涉及重要事项，建议直接咨询综合部或相关归口部门
```

## 重要约束

1. **不得编造**：严禁虚构制度名称、条款编号、审批层级、时限要求等。所有结论必须有原文支撑。
2. **原文优先**：答复中的制度依据必须尽量引用原文，不得擅自概括或改写为可能改变原意的表述。
3. **版本意识**：如检索到多个版本，优先引用最新版本，并标注版本号/发布日期。
4. **边界清晰**：本 skill 仅提供制度依据检索和初步答复，涉及最终解释权、争议裁定、特殊情况审批等事项，必须提示用户联系制度归口部门。
5. **保密意识**：制度文件可能涉及企业内部信息。禁止将文件内容用于回答无关问题，禁止泄露给无关人员。**禁止在答复中输出完整的制度文件内容，仅引用与问题直接相关的片段**，防止过度披露。

## 示例

**示例 1：正常查询**

输入：文件路径"./制度/考勤管理办法.docx"，问题"请假需要提前多久申请"

输出：

**简明结论**：病假需提前 1 天申请，事假需提前 3 天申请。

**置信度**：高

**制度依据**：
- 制度名称：《考勤管理办法（2024 版）》
- 条款位置：第四章第十八条
- 原文摘录："员工因病请假，应提前 1 个工作日向直接上级申请；因事请假，应提前 3 个工作日申请。"

**适用说明**：
- 适用对象/部门：全体员工
- 版本状态：现行有效（2024 年 3 月发布）

**风险提示**：
- 紧急情况无法提前申请的，应在返岗后 1 个工作日内补报
- 具体审批权限以各部门实际执行为准，如有疑问请联系人力资源部

**未明确事项**：
- 无

---

**示例 2：未找到依据**

输入：文件路径"./制度/报销管理办法.pdf"，问题"出国差旅的住宿标准是多少"

输出：

**检索结果**：未在《报销管理办法》中找到与"出国差旅住宿标准"直接相关的条款。

**已检索范围**：
- 检索的文件清单：《报销管理办法（2024 版）》
- 检索关键词：出国、境外、海外、差旅、住宿、标准

**建议**：
1. 确认是否使用了正确的制度文件或版本，出国差旅标准可能在《差旅费管理办法》或《国际差旅管理规定》中另行规定
2. 如涉及重要事项，建议直接咨询财务部或综合部

---

**示例 3：检索到矛盾条款**

输入：文件路径"./制度/"，问题"项目奖金的发放周期"

输出：

**简明结论**：检索到两项不同规定，存在版本差异，请向人力资源部确认当前执行标准。

**置信度**：低

**制度依据**：
- 制度名称：《项目激励管理办法（2023 版）》
  - 条款位置：第三章第五条
  - 原文摘录："项目奖金于项目验收通过后次月发放。"
- 制度名称：《项目激励管理办法（2024 修订版）》
  - 条款位置：第三章第六条
  - 原文摘录："项目奖金按季度统一结算，于每季度结束后 15 个工作日内发放。"

**适用说明**：
- 2023 版发布时间为 2023 年 6 月；2024 修订版发布时间为 2024 年 1 月
- 通常以最新版本为准，但需确认 2024 修订版是否已正式生效

**风险提示**：
- 两份文件对同一事项规定不一致，具体执行以人力资源部解释为准

**未明确事项**：
- 无法确认 2024 修订版是否已全面替代 2023 版，建议核实版本有效性
